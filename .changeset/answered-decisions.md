The fixer acts on a `Decision required:` thread once the developer has answered it: their latest comment is the call, carried out test-first where it changes behaviour, or declined when it keeps the code as it is or cannot be acted on without guessing. An unanswered decision stays out of the fixer's threads. The review prompt asks for a decision's options lettered, so a one-line answer can pick one.
